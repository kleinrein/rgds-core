# Top-bar status glyphs

Original code-drawn 28px sound, mute and Wi-Fi glyphs, generated by
`tools/build_status_icons.py`. Shapes are rendered at 4× then downsampled for
smooth edges. Each light/dark variant uses a high-contrast foreground and
subdued inactive Wi-Fi arcs. BMP V4 alpha preserves the bar background.
These small status indicators are independent of the category icon style.
