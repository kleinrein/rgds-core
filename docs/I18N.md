# Languages

Settings → System → Language selects English (US), Dansk, Deutsch, Español,
Français, Italiano, Nederlands, Norsk bokmål, Norsk nynorsk, Português (Brasil),
Português (Portugal), Suomi, Svenska or Tiếng Việt. English comes first; the
other languages are sorted by their native names. Swipe the list, drag or tap
the shared rounded scrollbar, use the mouse wheel,
or use the D-pad to move through every language. Scrolling keeps the focused
option visible and does not apply it; tap a row or choose Apply to save.
The selection is stored as `language` in the existing `ui.ini` and shared by the launcher and
in-game menu. Missing settings retain English. Changing language takes effect
immediately in the launcher and on the next opening of the in-game menu.

To add a language:

1. Copy `assets/locales/en-US.tsv` to a new file named for its language tag.
2. Keep each first column unchanged and translate the second column. Separate
   columns with one literal tab; use UTF-8 and one message per line.
3. Preserve `{0}` placeholders exactly. They carry dynamic values such as a
   game count or emulator name; they can move within a translated sentence.
4. Add the language tag and native name to `assets/locales/languages.tsv`,
   separated by a tab. Keep English first and sort the remaining native names.
   No launcher code change is necessary for registration.
5. Run the catalog checks in `tests/test_core_upgrade.py` and
   `tests/test_core_refinement.py`, plus the gesture checks in
   `tests/test_language_picker.py`. Build and inspect both screens, long labels,
   confirmation dialogs and all game-menu pages.

The first column is stable English source text. Unknown messages fall back to
that text. Game titles, ROM filenames, network names and user input are data,
not translation keys. External engine or system diagnostic text can also fall
back to its original language.

The pixel renderer supports Latin accents, ß and Bokmål Æ, Ø and Å, including
lowercase input. Vietnamese precomposed letters preserve both their vowel shape
and tone marks in the pixel typeface. The bundled rounded font covers every
character in all fourteen shipped catalogs; its Nunito source includes the
Vietnamese glyphs, baked into all five font sizes by `tools/bake_font.py`.
The catalogs include the update flow and statistics screens. A new language
with additional scripts requires extending font coverage and checking layout;
registering a catalog alone cannot supply missing glyphs.
