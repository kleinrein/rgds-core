# DSCore: RG DS fork of DSperate

This directory is the complete DSCore engine source: GPL-3.0-or-later, forked
from [beebono/DSperate](https://github.com/beebono/DSperate) at commit
`1b76c355109c9f7576363ccc023927b3137d3c6f` (tree `e8781d083ba9cbcf55e056a02d2b2f87d1a5e14e`).

Edit it directly. Behaviour and feature notes live in
[`src/experimental/rgds/README.md`](../src/experimental/rgds/README.md).

## Contents

`dscore/` is the canonical, editable source, including the hi-res Vulkan pipeline
(async compositor, GPU sequencing, store-out resolve, async renderer present).
It was seeded from the pinned upstream plus the RGDS patches and stylus/frontend
headers, then overlaid with the newest dev tree. Those patches are gone: nothing
applies a patch to this tree, and no upstream checkout is needed to build it.

Compiled SPIR-V (`src/core/gpu/vk/shaders/lean_*.spv`) is generated by
`tools/build_rgds_vulkan_shaders.py` into a build tree and is git-ignored here; do not commit it.

## Builds and fingerprint

`tools/build_rgds_experimental.py` (native) and `tools/build_rgds_vulkan.py` (hi-res)
compile a private copy of this tree under `build/`. `fork.source_hash()` is the SHA-256 of
every file's path and content here, except this file, `.DS_Store` and generated SPIR-V.
Builds record it (`source_hash`, and `base_source_hash` for Vulkan); `tools/package.py`
refuses an engine whose recorded hash no longer matches the tree, so after editing,
rebuild. Symlinks are refused, and this file must keep naming the upstream commit above.
`source.tar.gz` ships the tree as `DSperate/` beside the build recipe and this file.
`tests/test_dscore_fork.py` and `tests/test_dscore_build.py` check the tree and the build logic.

## Pulling upstream changes

Upstream history is not carried here. To rebase onto a newer DSperate, diff
upstream's pinned commit against the new one and apply it with `patch -p1`.
